# AI Slideshow Generator 🎬🖼️🔊

This project generates **AI-powered slideshow videos** from a text prompt.  
It uses **LLMs for script writing**, **image generation for scenes**, and **text-to-speech for narration** – combining them into a final video.

---

## 🚀 Features
- **Script Generation**: Creates a structured video script from a user prompt.
- **Image Prompt Expansion**: Extracts detailed scene prompts for image generation.
- **AI Image Generation**: Produces high-quality images for each scene.
- **AI Voice Narration**: Generates realistic voiceovers from the script.
- **Video Assembly**: Combines images and narration into a complete slideshow.
